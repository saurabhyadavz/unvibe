We sell credits for marking UPSC Mains answers: 1 credit = 1 answer marked against real toppers' answers. Free accounts get 3 copies a month. Paid plans: Mains 150 credits/month for ₹999 or 1,500 credits/year for ₹5,999; Max 300 credits/month for ₹1,799 or 4,000/year for ₹10,999; plus one-time top-ups of 50, 100 and 250 credits. Right now when a free user runs out we show an amber banner saying "Upgrade plan" and a pricing page that lists all four plans and the three top-ups in one grid. Hardly anyone converts.

Design the paywall a free user should see when they run out of credits: when it appears, which plans it shows and in what order, the exact on-screen copy (headline, plan labels, button text, the line about charging), what happens with the answers they have already had marked, and every state the screen can be in. Write it as paywall-spec.md. No code needed.
